# Linux Commands for Cybersecurity

A practical collection of Linux commands, examples, and cybersecurity use cases for learning Linux fundamentals.

## About This Project

This repository documents my hands-on learning of Linux commands and basic system administration concepts as part of my cybersecurity journey.

The goal is to understand how Linux systems work, become comfortable working from the terminal, and learn how common Linux commands can be used for system administration, networking, troubleshooting, and cybersecurity.

## What This Repository Covers

The commands and practical exercises are organized into different categories:

### 01 — File Management

Commands for navigating and managing files and directories.

### 02 — User Management

Commands for managing users, groups, and user information.

### 03 — Permissions and Ownership

Commands for understanding and managing Linux file permissions and ownership.

### 04 — Networking

Commands used to inspect network interfaces, connections, routes, DNS, and network connectivity.

### 05 — Process Management

Commands for viewing, managing, and troubleshooting running processes.

### 06 — System Information

Commands for checking system information, hardware, memory, storage, and system resources.

### 07 — Package Management

Commands for installing, updating, removing, and managing software packages.

### 08 — Log Analysis

Commands for viewing and analyzing system logs and other useful information for troubleshooting and security investigations.

## Command Documentation

For each command, I will document:

* What the command does
* Basic syntax
* Practical examples
* Important options
* Possible cybersecurity or system administration use cases

## Environment

The commands in this repository are primarily practiced in:

* Kali Linux
* Linux terminal

Some commands may behave differently depending on the Linux distribution or system configuration.

## Learning Approach

This repository is part of my ongoing cybersecurity learning journey. The focus is on **understanding and practicing commands**, rather than simply memorizing them.

As I learn new commands and concepts, this repository will be updated with additional examples and practical exercises.
